## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

1. **Do not create a public issue**: Please avoid opening public GitHub issues for sensitive security bugs.
2. **Contact Privately**: Send details via GitHub Security Advisory (preferred) or email the maintainer directly at `ronaldrex.ch@gmail.com`.
3. **Include Details**: Provide a description of the vulnerability, affected components, reproduction steps, and potential impact.

Reports will be reviewed and acknowledged promptly.
